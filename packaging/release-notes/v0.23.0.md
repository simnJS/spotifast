Spotifast 0.23.0 fait se comporter la file d'attente et la lecture aléatoire comme dans l'application Spotify. Si vous avez déjà une version 0.18 ou plus, l'application vous propose cette mise à jour toute seule.

**Télécharger :** [Windows (installateur)](https://github.com/simnJS/spotifast/releases/download/v0.23.0/spotifast-v0.23.0-x86_64-pc-windows-msvc.msi) · [Windows (ZIP portable)](https://github.com/simnJS/spotifast/releases/download/v0.23.0/spotifast-v0.23.0-x86_64-pc-windows-msvc.zip) · [Linux (AppImage)](https://github.com/simnJS/spotifast/releases/download/v0.23.0/spotifast-0.23.0-x86_64.AppImage) · [Linux (archive)](https://github.com/simnJS/spotifast/releases/download/v0.23.0/spotifast-v0.23.0-x86_64-unknown-linux-gnu.tar.gz)

## Nouveautés

- **L'aléatoire par playlist et par album.** Chaque playlist, album ou liste de titres likés garde son propre mode aléatoire, comme dans Spotify. Le bouton d'une page règle cette page sans remélanger ce qui joue, et le premier morceau est tiré dans toute la collection.
- **La file telle que Spotify la voit.** Avec Soloist, « À suivre dans la file », « À suivre depuis » et « À suivre » viennent directement du lecteur, y compris les morceaux mis en file depuis votre téléphone.
- **Modifier la file avec Soloist** : retirer, déplacer, insérer ou vider, et cliquer sur un morceau pour y aller directement, sans jouer ceux du dessus.
- **« Vider la file » demande confirmation.**

## Corrigé

- **Le bouton aléatoire montre l'état réel du lecteur.**
- **Un lancement en aléatoire ne bloque plus la lecture** quand ce qui joue interdit l'aléatoire (correctif de v14, crmne/spotifast#1348).
- **Un morceau lancé seul en aléatoire garde l'enchaînement automatique.**
- **La file est retrouvée après un redémarrage** de Spotifast.

## Installer

Voir les instructions de la [version 0.18.0](https://github.com/simnJS/spotifast/releases/tag/v0.18.0). Sous Windows, l'application n'est pas signée : à l'avertissement SmartScreen, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
