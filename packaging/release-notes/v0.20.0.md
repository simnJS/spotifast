Spotifast 0.20.0 peut se connecter à un serveur de statistiques, pour des stats complètes même quand votre ordinateur est éteint. Si vous avez déjà une version 0.18 ou 0.19, l'application vous propose cette mise à jour toute seule.

**Télécharger :** [Windows (installateur)](https://github.com/simnJS/spotifast/releases/download/v0.20.0/spotifast-v0.20.0-x86_64-pc-windows-msvc.msi) · [Windows (ZIP portable)](https://github.com/simnJS/spotifast/releases/download/v0.20.0/spotifast-v0.20.0-x86_64-pc-windows-msvc.zip) · [Linux (AppImage)](https://github.com/simnJS/spotifast/releases/download/v0.20.0/spotifast-0.20.0-x86_64.AppImage) · [Linux (archive)](https://github.com/simnJS/spotifast/releases/download/v0.20.0/spotifast-v0.20.0-x86_64-unknown-linux-gnu.tar.gz)

## Nouveautés

- **Un serveur de statistiques.** Dans les réglages, la section « Serveur de statistiques » connecte Spotifast à un serveur [spotifast-stats-api](https://github.com/simnJS/spotifast-stats-api) : cliquez sur « Se connecter », acceptez sur Spotify dans votre navigateur, et Spotifast est connecté. Le serveur relève vos écoutes toutes les deux minutes, jour et nuit, même quand Spotifast est fermé ; Spotifast les récupère toutes les 20 minutes et vos stats sont complètes.
- **L'import de votre historique** est aussi envoyé au serveur quand vous êtes connecté.

Votre jeton de connexion est gardé dans le trousseau sécurisé de votre système.

## Installer

Voir les instructions de la [version 0.18.0](https://github.com/simnJS/spotifast/releases/tag/v0.18.0). Sous Windows, l'application n'est pas signée : à l'avertissement SmartScreen, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
