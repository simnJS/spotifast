Spotifast 0.22.0 rend la file d'attente plus proche de celle de Spotify. Si vous avez déjà une version 0.18 ou plus, l'application vous propose cette mise à jour toute seule.

## Nouveautés

- **Ajouter une playlist, un album, vos titres likés ou un artiste à la file** d'un clic droit : tous les morceaux sont ajoutés dans l'ordre, après ceux déjà en file (pour un artiste, ses titres populaires).

## Corrigé

- **La lecture continue après la file d'attente.** Quand la file se vide, Spotifast reprend la playlist ou l'album en cours, puis enchaîne sur des recommandations si l'enchaînement automatique est activé, au lieu de s'arrêter.
- **Cliquer sur un morceau loin dans la file** le lance directement, sans jouer un instant ceux du dessus (correctif de bompus, crmne/spotifast#1317).
- **Les morceaux de remplissage de Spotify** n'apparaissent plus dans « À suivre » (correctif d'Espaye, crmne/spotifast#1192).

## Installer

Voir les instructions de la [version 0.18.0](https://github.com/simnJS/spotifast/releases/tag/v0.18.0). Sous Windows, l'application n'est pas signée : à l'avertissement SmartScreen, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
